Ссылка на проект: https://github.com/theskumar/python-dotenv

Описание: Библиотека python-dotenv считывает пары ключ-значение из файла .env и может устанавливать их в качестве переменных окружения. Она помогает в разработке приложений, соответствующих принципам 12-факторной архитектуры.

До добавления тестов: 84 процента покрытия кода

После добавления тестов: 85 процентов покрытия кода

Описание покрытого тестами функционала:
проверка что значение одной переменной может ссылаться на другую через синтаксис ${VAR}, и подстановка происходит корректно.
проверка механизма значения по умолчанию (${VAR:-default}): если переменная не определена, подставляется указанное значение по умолчанию.
проверка что последовательность $$ интерпретируется как один литеральный символ $, а не как начало интерполяции, то есть тестирует экранирование.

Используемые технологии и библиотеки:
Язык: Python
Фреймворк тестирования: pytest
Измерение покрытия: coverage.py, плагин pytest-cov
